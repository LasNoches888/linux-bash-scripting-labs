# Лаба 4: Обработка текста (grep, awk, sed, sort)

Для упражнений используйте `tests/data/access.log` — 7 строк лога в формате nginx/Apache combined.

## Задания

1. Выведите только запросы с ошибками (статус 4xx и 5xx).
2. Посчитайте количество запросов по каждому IP и выведите топ.
3. Посчитайте суммарный объём переданных данных (последняя колонка).
4. Выведите уникальные запрошенные URL.
5. Замените в выводе IP-адреса на `x.x.x.x` (анонимизация перед публикацией лога).

## Решения

```bash
LOG=tests/data/access.log

# 1. $9 — поле со статусом; сравниваем как число
awk '$9 >= 400' "$LOG"

# 2. Ключевая связка: sort | uniq -c | sort -rn
awk '{print $1}' "$LOG" | sort | uniq -c | sort -rn

# 3. Суммирование в awk
awk '{bytes += $10} END {print bytes " байт"}' "$LOG"

# 4. $7 — путь запроса
awk '{print $7}' "$LOG" | sort -u

# 5. sed с расширенными регулярными выражениями
sed -E 's/^([0-9]+\.){3}[0-9]+/x.x.x.x/' "$LOG"
```

Ожидаемые значения для тестового файла:
- задание 1 — 3 строки (статусы 404, 403 и 500);
- задание 2 — `10.0.0.1` с тремя запросами, затем `10.0.0.2` с двумя;
- задание 3 — `2197 байт`;
- задание 4 — шесть уникальных путей: `/`, `/about`, `/admin`, `/api/report`, `/login`, `/missing`.

> Проверьте себя: почему статус 302 (редирект после `POST /login`) не попал в результат задания 1?

## Шпаргалка

| Задача | Команда |
|--------|---------|
| строки, содержащие слово | `grep -i "error" file` |
| строки без слова | `grep -v "debug" file` |
| N-я колонка | `awk '{print $N}'` |
| разделитель — двоеточие | `awk -F: '{print $1}'` |
| первые / последние строки | `head -n 5` / `tail -n 5` |
| следить за файлом | `tail -f file` |
| замена в потоке | `sed 's/old/new/g'` |
| подсчёт строк | `wc -l` |
