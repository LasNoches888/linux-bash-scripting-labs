# Лаба 3: Функции, коды возврата и trap

## Задания

1. Вынесите логирование в функции (`log_info`, `log_error`) и подключите их из отдельного файла — см. `scripts/lib/common.sh`.
2. Напишите функцию `is_number`, возвращающую 0 для целых чисел, и используйте её в `if`.
3. Скрипт создаёт временный каталог. Гарантируйте его удаление при любом завершении — даже при Ctrl+C или ошибке.
4. Пусть скрипт блокирует повторный запуск (lock-файл).

## Решения

```bash
# 1. В скрипте:
source "$(dirname "${BASH_SOURCE[0]}")/lib/common.sh"
log_info "начинаем"

# 2. Функция возвращает код, а не «значение»: 0 = истина
is_number() { [[ "$1" =~ ^-?[0-9]+$ ]]; }
if is_number "$x"; then echo "число"; fi

# 3. trap EXIT срабатывает при нормальном выходе, ошибке (set -e) и сигналах INT/TERM
tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT
trap 'exit 130' INT TERM          # чтобы Ctrl+C вызвал EXIT-обработчик

# 4. Блокировка через flock (если нет flock — mkdir атомарен и подходит как замок)
exec 9>/tmp/myscript.lock
flock -n 9 || { echo "уже запущен" >&2; exit 1; }
```

## Коды возврата

| Код | Значение |
|-----|----------|
| 0 | успех |
| 1 | общая ошибка |
| 2 | неверное использование (аргументы) |
| 126 | файл найден, но не исполняемый |
| 127 | команда не найдена |
| 130 | прерван по Ctrl+C |

Скрипты в `scripts/` следуют этому соглашению: `healthcheck.sh` возвращает 0/1/2, `disk_alert.sh` — 0/1.
